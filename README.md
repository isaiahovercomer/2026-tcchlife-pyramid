# 2026-tcchlife-pyramid

台中市召會聚會人數年度統計互動網頁。

- `index.html`：互動式人口金字塔（年份 2023–2026 實際、2027／2030／2035／2040 趨勢延續預估；範圍含台中市召會總數、南／北／西／中各照顧區方位合計、10 個照顧區合計、41 大區；大區依十個照顧區順序排列；範圍選單在年份按鈕上方，年份分實際／預估兩行對齊；金字塔下年輕上年長、色塊填滿且左右在中間接觸、可切換輪廓線與大致形狀；金字塔下方圖例旁有燈號總結，下方有統計卡片，金字塔下方有「一鍵截圖」按鈕，旁邊有「一鍵投影」按鈕（點開為橫版 4:3 投影畫面：標題、目前顯示、年齡、金字塔、總結與統計，附退出按鈕與 Esc 退出，並嘗試全螢幕）；大致輪廓下方有兒童／青少年／大專／青職特別年齡段按鈕（點選 dim 其他段並以金框凸顯該段高度，明細列顯示該段加總；選取時總結卡片改為該年齡層的動能分析：人數、佔比、趨勢與注意事項）；一鍵截圖上方有「尋求突破」卡片（六個每年帶進按鈕以三欄網格對齊排列：兒童、青少年、大專、青職同一綠色，青年人單獨藍色，其他年齡單獨灰藍色，點選後標題旁出現清除按鈕與模擬說明；無年期按鈕，模擬以 2026 年為起點、以上方所選年份為目標，2027 年為 1 年後、2030 年為 4 年後、2035 年為 9 年後、2040 年為 14 年後，選實際年份時顯示該年實際數據；每年先老化一年再帶進當年的人，帶進的人男女各半、年齡在該段內均勻分布，大專指 19–22 歲、青職指 23–35 歲、青年人指 0–35 歲、其他年齡指 36 歲以上，量級為大區每組 10 人、照顧區每組 50 人、方位合計每組 50×照顧區數、全召會每組 500 人，按鈕文字隨範圍更新；模擬時金字塔、統計卡片與總結卡片皆改為模擬結果，總結卡片比較模擬與不行動的總數、青年、幼年、高齡占比與形狀並給燈號定性）；實際年份用深色、預估年份用淺色；開啟時浮動視窗請輸入出生年，金字塔上方隨年份顯示年齡與人生階段色調）
- `forecast.js`：趨勢延續推估模型（年齡推移＋2023→2025 各段實際變化率＋台中市粗出生率推估出生；方法詳見網頁「預估方法與假設」）
- `pyramid-data.json`：年齡 × 性別數據（來源：召會生活人數統計 chlife-stat.org 報表 → 年齡結構匯出；主日、常聚會 ≥2 相異週、身分全部含福音朋友；製表 2026-10-26）

開啟方式：GitHub Pages（Settings → Pages → Deploy from a branch → main → /(root) → Save），網址為 https://isaiahovercomer.github.io/2026-tcchlife-pyramid/
